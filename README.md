# Brand Kit Lite

A local, no-key event-artwork tool for independent music and small content teams. Set one visual identity, import an event CSV, inspect row-level checks, and export a coordinated set of posters, stories and banners.

The interface is Chinese. Documentation is English. This is a deliberately constrained template tool, not a general design editor or AI image generator.

## Run locally

Extract the complete folder. With Python 3 installed, open a terminal in that folder:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

On Windows, use `py -3 -m http.server 8000 --bind 127.0.0.1` if needed. Open **http://127.0.0.1:8000**. Stop the server with Ctrl+C.

Python only serves static files. The app has no backend, accounts, API keys, subscriptions, external fonts, remote assets, telemetry, or paid services. Do not serve private files from a shared parent directory. Opening index.html directly with file:// has not been verified.

## Workflow

1. Replace the fictional sample brand and events with your own.
2. Set background, accent and one of three original geometric motifs.
3. Edit individual events or download the CSV template and import up to 30 rows.
4. Review every row's blocking issues and warnings. Invalid dates, duplicates, invalid colors and template-capacity failures block export.
5. Inspect each of the three size previews. Export one SVG or browser-rendered PNG, or a ZIP of all SVGs plus manifest and preflight results.
6. Save a JSON workspace before closing. Restore it later. Failed imports leave the current workspace unchanged. One-level undo covers the last import, add or delete, not individual typing.

Nothing is persisted automatically. Reloading the page loses unsaved work. Export downloads depend on browser settings; a download request is not proof that a file was saved.

## CSV

Supported headers: `id,title,date,time,venue,performer,cta`. Chinese aliases are accepted. Required columns: title, date, venue. Missing IDs are generated by row order.

Dates use YYYY-MM-DD; optional times use 24-hour HH:MM. UTF-8 BOM, CRLF and quoted commas are supported. Embedded newlines/control characters are not supported in artwork fields.

Limits: 256 KiB CSV, 30 events, 1,000 code units per parsed cell. Artwork limits: brand 24 characters, tagline 52, ID 40, title 40, venue 42, performer 60, CTA 28. A title within its character limit can still exceed a template's capacity. Draft imports may contain business-invalid fields so they can be corrected in the editor. Unknown or ambiguous columns are rejected.

## Exports

- Poster: 1080 × 1350
- Story: 1080 × 1920
- Banner: 1500 × 500
- ZIP: three SVGs per event, manifest.json and README.txt. Stable ASCII row-number filenames avoid collisions across Chinese titles; the manifest maps rows to their original IDs.
- PNG: current event and size only, rendered locally by the browser.
- Workspace JSON: brand configuration and full event list.
- Preflight JSON: row results, color calculations and the check method.

All exports contain user-provided event data. Workspace and manifest files may include private drafts. Inspect before sharing. SVG text stays editable, but recipients need compatible fonts; use PNG when fixed rendering matters.

## What the checks mean

Text/background contrast is calculated with the WCAG relative-luminance formula. A requested accent below 4.5:1 is replaced with the selected black/white text color, with a warning for every affected event. Decorative motifs are clipped away from text regions. This is a template-specific safeguard, **not an accessibility certification**.

Layout checks use deterministic character-width estimates, line limits and fixed template geometry. SVG textLength constrains text width; excessive performer compression and title/information overlap are rejected. These are **not Canvas-measured glyph overflow checks**. CJK fallback fonts, emoji, unusual scripts and compressed text can differ between browsers. Inspect every final export at its actual size. Content correctness, rights, platform cropping and actual readability remain human checks.

## Comparison and validation

See COMPARISON.md for a fixed-version, narrowly scoped source comparison. It does not claim general superiority over a full design editor.

Internal validation: 54 Node tests cover core rules, CSV bounds, XML escaping, ZIP integrity, backup validation, malformed-import preservation, undo and asynchronous import ordering. SVGs were rasterized with Inkscape for inspection. The release ZIP was downloaded and extracted, then tested in the cloud browser through localhost: two-event CSV import, long-title blocking, low-contrast fallback, actual PNG/SVG/ZIP opening, workspace backup restoration, and 1180 px / 400 px viewport layouts passed. This validates that browser and local static-server workflow only. A narrow viewport is not a physical-phone test. Tests and QA artifacts are intentionally outside this public package. Other browsers, physical mobile devices, print color accuracy and file:// launching remain unverified.

## Scope

No freeform canvas, photo upload, logo generation, batch PNG, CMYK/PDF print production, remote synchronization or automatic publishing. No promise of commercial results. Designed to make a small recurring event series consistent without hiding risky input.
